# Productivity IQ

## 📌 Overview
Productivity IQ is a personalized machine learning system that predicts a student's study focus level using behavioral, academic, and environmental data.

## 🎯 Objectives
- Predict study focus level
- Analyze productivity patterns
- Provide personalized study recommendations
- Improve learning efficiency using Machine Learning

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit
- Git & GitHub
